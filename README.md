Diseño y Programación en Bases de Datos Oracle

Repositorio de prácticas

Descripción

Este repositorio contiene prácticas desarrolladas durante la cursada de la materia Diseño y Programación en Bases de Datos Oracle, dictada por la docente Gabriela Velázquez.

El objetivo es aplicar de manera progresiva conceptos de bases de datos relacionales, SQL y PL/SQL utilizando Oracle Database.

Objetivos del repositorio
Modelado de bases de datos relacionales.
Desarrollo de consultas SQL de complejidad progresiva.
Implementación de estructuras de control en PL/SQL.
Creación de procedimientos, funciones y triggers.
Manejo de excepciones y cursores.
Uso de packages, jobs y transacciones autónomas.
